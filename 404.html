How it works

Three steps, and nothing to babysit.

No crawler approval queue and no sync job. Search is built and shipped with the rest of your site.

  1. 1

    Install the plugin

    Add docusaurus-plugin-docsense to your Docusaurus config. The SearchBar lands in the navbar automatically.

    // docusaurus.config.js
plugins: ['docusaurus-plugin-docsense'],
  2. 2

    Build your docs

    Run your normal build. Docsense indexes your Markdown and MDX and ships the result as a static JSON file.

    # your usual build
npm run build
  3. 3

    Search in the browser

    Readers open search with a shortcut and query the index locally. No account and no server to run.

    ⌘KorCtrlK

Choosing a search tool

When to use Docsense.

Choose Docsense

Fits when
  • You want search inside your Docusaurus build
  • Index freshness must match every deploy
  • You prefer a static JSON file you own
  • Private or internal docs should not leave your boundary for indexing

Choose hosted search

  • You need a managed cloud search platform
  • You already run Algolia or similar at scale
  • You want Ask AI or chat answers from the same vendor
  • You need multi-product search beyond docs Markdown
