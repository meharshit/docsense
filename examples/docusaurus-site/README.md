# Docsense documentation site

This Docusaurus site is the product documentation for **Docsense**.

It is also a live demo: press **⌘K** / **Ctrl+K** to search these pages with Docsense.

## Run locally

From the Docsense monorepo root (or this folder after workspace install):

```bash
cd examples/docusaurus-site
npm start
```
