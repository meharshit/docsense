# Support

Docsense is an open-source project. Use the channels below for bugs, questions, and contributions.

## Report a bug or request a feature

Open an issue on GitHub:

[github.com/meharshit/docsense/issues](https://github.com/meharshit/docsense/issues)

Include:

- Docsense / plugin version (or git commit)
- Docusaurus version
- Steps to reproduce
- Expected result and actual result
- Relevant config snippets (`docusaurus.config` plugin options, not secrets)

## Ask a question

Use GitHub Issues for product questions that may help other readers, or start a discussion on the repository if Discussions are enabled for the project.

Before you open a new thread, check:

- [FAQ](/docs/faq)
- [Install Docsense](/docs/how-to/install)
- [Plugin options](/docs/reference/plugin-options)

## Security

If you believe you found a security issue in Docsense, do not file a public issue with exploit details. Contact the maintainer through GitHub and mark the report as security-sensitive when the repository supports that workflow.
