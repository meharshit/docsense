# Basic Docsense example (CLI)

Minimal smoke example for `@docsense/indexer` + `@docsense/core` without Docusaurus.

```bash
npm run index   # build static/docsense/search-index.json
npm run search -- instal
```

The marketing docs site lives in `examples/docusaurus-site`. This folder is for quick CLI checks only. Generated `search-index.json` is gitignored.
